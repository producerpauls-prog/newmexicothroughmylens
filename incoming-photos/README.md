# Upload photographs here

Upload full-resolution JPEG files to this folder on the `main` branch. The filename can be anything ending in `.jpg` or `.jpeg`.

The automated workflow will:

1. verify that the file is a real JPEG;
2. preserve the original bytes;
3. assign the next unused `NM-###` photograph ID;
4. publish it to `print-assets/NM-###.jpg`;
5. add it to `photos.json`; and
6. remove the processed file from this folder.

Do not upload customer information or private photographs. Published print assets are public so Prodigi can download them.
